# Changelog

## v1.3 (Текущая версия)

### Новые функции:
- ⏱ **Управление интервалом опроса в Telegram:**
  - В главное меню и команды добавлена кнопка **«⏱ Интервал опроса»** (`/interval`).
  - Отображает текущую установленную частоту опроса (например: `60 мин (1 час)`).
  - Быстрый выбор готовых интервалов: `5 мин`, `15 мин`, `30 мин`, `1 час`, `2 часа`.
  - Возможность ручного ввода любого количества минут через FSM.
  - Автоматическое обновление `pause_general` в `config.toml` и перезапуск парсера.

- 🏷 **Понятные названия для поисков:**
  - При добавлении ссылки бот предлагает ввести удобное имя (например: `Raspberry Pi 4 2-3k`) или взять автоматически из текста ссылки.
  - В списке отображаются имена вместо длинных нечитаемых ссылок.

- ⏸ **Пауза и возобновление поисков (без удаления):**
  - В карточке каждого поиска появилась кнопка **«⏸ Поставить на паузу»** / **«▶️ Включить поиск»**.
  - Поиски на паузе исключаются из конфигурации парсера, но сохраняются в базе.
  - В списке поиски наглядно помечаются значками `🟢` (активен) или `⏸` (на паузе).
