# Avito Manager

> Telegram-бот для удобного управления Docker-контейнером [Parser Avito](https://github.com/Duff89/parser_avito).

---

## 🚀 Возможности

- ➕ **Добавление поисков в 2 шага**: отправка ссылки с валидацией и задание понятного названия (или автогенерация).
- 🏷 **Понятные имена**: поиски отображаются по человекочитаемым заголовкам, а не длинным ссылкам.
- ⏸ **Пауза и запуск**: возможность временно остановить отслеживание любого поиска без его удаления из базы.
- ⏱ **Управление интервалом опроса**:
  - Быстрый выбор частоты: `5 мин`, `15 мин`, `30 мин`, `1 час`, `2 часа`.
  - Возможность ручного ввода любого количества минут.
  - Отображение текущей частоты опроса в меню и по команде `/interval`.
- 📋 **Просмотр логов в реальном времени**: вывод последних строк логов работы парсера прямо в чат Telegram (`/logs`).
- 📊 **Мониторинг статуса**: отображение состояния контейнера, интервала и количества активных ссылок.
- 🔄 **Автоматическая синхронизация**: обновление `config.toml` и перезапуск контейнера парсера при любых изменениях.
- 📦 **Контроль версий**: проверка локальной и удаленной версии на GitHub, безопасное обновление (`/update`) с защитой от перезаписи локальных файлов.

## 🛠 Стек технологий

- **Python 3.11+**
- **Aiogram 3.x** (FSM, Polling, Asyncio)
- **Docker SDK** (`docker-py`)
- **SQLite 3**
- **Docker & Docker Compose**

## 📁 Структура проекта

```
├── bot.py                  # Точка входа, команды, FSM-обработчики и меню
├── config_generator.py     # Модуль инъекции ссылок и интервалов в config.toml
├── init_db.py              # Инициализация базы данных (выполняется и автостартом)

├── modules/
│   ├── database.py         # Работа с SQLite (таблица searches, миграции)
│   ├── docker_manager.py   # Взаимодействие с Docker Daemon (restart, status, logs)

├── deploy.sh               # Скрипт автоматического развертывания на VPS в один клик
├── Dockerfile              # Docker-образ менеджера на python:3.11-slim
├── docker-compose.yml       # Конфигурация Docker Compose
├── .env.example            # Пример файла окружения (шаблон с инструкцией)

```

## ⚙️ Настройка конфигурации (.env)

Перед запуском создайте файл конфигурации `.env` на основе примера:

```bash
cp .env.example .env
nano .env
```

Заполните ваши данные:

```ini
# 1. Токен вашего Telegram-бота (получить в @BotFather)
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ

# 2. Ваш числовой Telegram ID (узнать свой ID можно в @userinfobot)
# Если администраторов несколько, укажите их через запятую: 123456789,987654321
ADMIN_IDS=123456789

# 3. Системные пути внутри контейнера (по умолчанию)
CONFIG_PATH=/opt/parser_avito/config.toml
PARSER_PATH=/opt/parser_avito
PARSER_CONTAINER_NAME=avito
DB_PATH=searches.db
```

> [!IMPORTANT]
> Никогда не коммитьте файл `.env` в публичный репозиторий! Файл `.env` уже внесен в `.gitignore`.

## 🖥️ Быстрое развертывание на сервере (VPS)

Скрипт развертывания автоматически проверит и установит Docker (если нужно), клонирует и настроит репозиторий `parser_avito`, подготовит базу данных и запустит оба контейнера.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/crosf/avito-manager.git /opt/avito_manager
cd /opt/avito_manager

# 2. Настройте файл .env (укажите свои BOT_TOKEN и ADMIN_IDS)
cp .env.example .env
nano .env

# 3. Запустите автоматическое развертывание
chmod +x deploy.sh
sudo ./deploy.sh
```

После завершения оба сервиса будут работать в фоновом режиме:
- `avito_manager` — бот управления
- `avito` — парсер объявлений

## 🤖 Команды Telegram-бота

- `/start` — главное меню и текущая статистика
- `/list` — список сохранённых поисков с возможностью паузы/запуска/удаления
- `/interval` — просмотр и изменение частоты поиска
- `/reload` — обновить конфиг и принудительно перезапустить парсер
- `/logs` — получить последние строки логов работы парсера
- `/status` — проверить состояние контейнеров
- `/version` — текущая и последняя версии парсера на GitHub
- `/update` — обновить парсер из официального репозитория
